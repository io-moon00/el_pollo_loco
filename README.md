# 🐔 El Pollo Loco – The Crazy Chicken Chase

**El Pollo Loco** is a fun 2D platformer built with **JavaScript**, **HTML5 Canvas**, and **CSS**.  
Join **Pepe**, the brave adventurer, on his spicy mission to collect salsa bottles and coins, defeat wild chickens and chicks, and face the fiery boss **El Pollo Diablo**! 🌶️🔥  

---

## 🎮 Gameplay

- Move Pepe through a colorful world filled with crazy chickens.  
- Collect **coins** to increase your score.  
- Gather **salsa bottles** to prepare for the ultimate boss fight.  
- Avoid enemies and reach the end to claim victory!  
- Win against **El Pollo Diablo** to prove you’re the ultimate chicken hero. 🏆  

---

## ✨ Features

- 🪶 Smooth character movement and collisions  
- 🌶️ Themed screens: Help, Settings, Win & Orientation message  
- 🔊 Toggleable sound and music controls  
- 🧭 Mobile-friendly with rotation detection  
- 💻 Built using pure **JavaScript (ES6)** and **Canvas API**

## 🏠 Run Locally

You can run **El Pollo Loco** locally in just a few seconds — no build tools needed.

### Option 1: Using VS Code + Live Server (recommended)
1. Open the project folder in **Visual Studio Code**.  
2. Install the **Live Server** extension (if not already installed).  
3. Right-click `index.html` → **Open with Live Server**.  
4. Your browser will open automatically at `http://localhost:5500/`.

### Option 2: Using a simple local web server
If you prefer another editor or command line:
```bash
# Python 3
python -m http.server 5500

# or Node.js (if installed)
npx serve -l 5500
